# تخصص‌های لازم برای بازبین فنی سیستم خزانه‌داری

> این فهرست از روی **کد فعلی مخزن** (۲ آذر ۱۴۰۵، 23 Nov 2026) و کارهای پیش رو (ورود با Keycloak و چندشرکتی، پرداخت‌ها و چاپ چک، ارسال سند به دفتر کل در فاز F) تهیه شده است. برای هر تخصص، **عمق لازم از ۱ تا ۱۰** برای دو نقش آمده است: بازبین اصلی و بازبین دوم. تقسیم کار این دو در `docs/reviewer-workflow.fa.md` (بخش «تقسیم کار بین دو بازبین») آمده است.
> عددها پیشنهاد است و تصمیم نهایی با مالک محصول است.

## ۱. معنای عددها

| عمق | معنا |
|---|---|
| **۱–۲** | فقط نامش را شنیده یا خوانده است |
| **۳–۴** | با راهنمایی و نمونه کار کرده است؛ کد آن را می‌خواند ولی خطای ظریفش را نمی‌بیند |
| **۵–۶** | کار روزمره را مستقل انجام می‌دهد؛ اشتباه‌های رایج را در بازبینی می‌گیرد |
| **۷–۸** | چند سال تجربه در سیستم واقعی در حال کار؛ مشکل سخت را حل می‌کند و می‌تواند بگوید **چرا** یک راه درست است و راه دیگر نه |
| **۹–۱۰** | مرجع و متخصص؛ دیگران برای تصمیم‌های دشوار از او می‌پرسند |

در جدول‌ها، تخصص‌هایی که برای استخدام نیروی جدید (بازبین دوم) **حداقل لازم** هستند با ★ نشان داده شده‌اند. کمبود در بقیه را می‌شود در ماه‌های اول با مسیر یادگیری `docs/reviewer-guide.fa.md` (فصل ۱۴) جبران کرد.

## ۹. خلاصه برای آگهی استخدام بازبین دوم

**حتماً داشته باشد (حداقل‌ها):**

- حسابداری دوطرفه و کدینگ حساب‌ها (کل، معین، تفصیل): **۸**
- بازبینی کد و تجربه کار با Pull Request در GitHub: **۸** و **۷**
- عملیات خزانه‌داری و چک در ایران: **۷**
- TypeScript و Vue 3، رابط فارسی واکنش‌گرا: **۷**
- C# و .NET 10، طراحی آزمون: **۶**
- لینوکس، Docker و امنیت وب: **۶**
- SQL در PostgreSQL: **۵**

**امتیاز اضافه:** PostgreSQL پیشرفته، Keycloak و OpenID Connect، Module Federation، آشنایی با MS Access یا سیستم‌های حسابداری ایرانی.

**نکته:** پیدا کردن کسی که هم حسابداری را در عمق ۸ بداند و هم برنامه‌نویسی را، سخت است. اگر باید بین این دو انتخاب کرد، برای بازبین دوم **حسابداری و دانش خزانه‌داری** مهم‌تر است: خطاهای فنی را CI و بازبین اصلی می‌گیرند، ولی سند با بدهکار و بستانکار اشتباه از هیچ آزمون خودکاری رد نمی‌شود، مگر کسی که حسابداری می‌داند آن را ببیند.
